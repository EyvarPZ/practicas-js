# Prácticas de JS
 
Colección de ejercicios de lógica de programación en **JavaScript**, reunidos en una interfaz web sencilla que permite ejecutar cada práctica desde un menú principal.

## Descripción
 
La página principal (`index.html`) presenta un menú con un botón por práctica; al seleccionarlo se ejecuta el código correspondiente.

## Ejercicios 
 
| # | Práctica | Conceptos principales |
|---|----------|-----------------------|
| 1 | Suma de dos números | Entrada de datos, operaciones aritméticas |
| 2 | Número positivo o negativo | Condicionales |
| 3 | Calculadora | Operaciones básicas, selección de operación |
| 4 | Suma de números pares e impares | Ciclos, condicionales, acumuladores |
| 5 | Tabla de multiplicar | Ciclos |
| 6 | Jubilación | Ciclos, condicionales con múltiples criterios |

## Tecnologías
 
- **HTML5** para la estructura del menú.
- **CSS3** para el diseño y los estilos de los botones.
- **JavaScript (ES6)** para la lógica de cada práctica.
